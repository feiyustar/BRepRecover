# Release Plan

The project selected MIT for authorized project code on 2026-11-06. This does not authorize a public release, upload, model publication, or training run. This is an installable prototype, not a validated end-to-end release.

## Gates

1. Ownership/source: confirm provenance and redistribution rights for included extracted behavior; confirm rights for excluded baseline-derived generate.py and brepBuild.py before considering them; document third-party adaptations. MIT selection does not resolve these reviews.
2. Minimal core: extract modules into evidence, selection, recovery, validation, pipeline, training, and adapters boundaries. Begin with pure selection utilities; keep unresolved builder code out.
3. Dependencies: choose/test exact Python, PyTorch, Gmsh, OCC/PythonOCC, occwl, and platform versions; record licenses/notices and reproducible environment information.
4. Artifacts: determine whether generator and learned selector/backbone weights can be linked or redistributed. If not, document the access route and that code alone cannot reproduce metrics. Do not commit data, feature caches, checkpoints, experiment results, or credentials.
5. Tests: add deterministic unit tests for feature ordering and selector decisions; add isolated CAD-kernel/STEP tests only in a separately configured optional integration environment.
6. Claims: limit claims to failure-only wrapper-level recovery on evaluated cohorts. Do not claim learned-selection superiority, universal recoverability, geometric fidelity from online validity, or engineering/manufacturing readiness.
7. Release: after prior gates, verify notices/citations, local paths/secrets/artifacts, and prepare a versioned release. The source tree is technically installable as a prototype, but the selected MIT license does not resolve included-source provenance or authorize public release of unreviewed material.

## Implemented Prototype Scope

The prototype includes the Stage278P candidate scoring architecture and 138-D input contract, Stage286R-T 12-D shape scorer and 0.561 gate, shape aggregate, tensor-only feature adapter protocol, connected selector/recovery coordinator, thin acceptance protocol, and artifact-path validation CLI. Extracted behavior is based on current research source; owner confirmation remains pending. This is not a clean-room or license-cleaning claim. No checkpoint, generator, feature backbone, concrete feature adapter, geometry builder, concrete validator, dataset, or results are included.

Next work requires ownership and dependency review before online feature extraction or a concrete CAD backend. Do not extract brepBuild.py or gmsh_recovery_sidecar.py until lineage and dependencies are cleared. A real timeout guarantee requires backend-enforced isolation, not just the protocol parameter.
